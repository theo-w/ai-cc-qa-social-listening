# SDD-006 UI/UX 规范

> 版本：v0.1.0 ｜ 状态：已冻结（Baseline） ｜ 更新：2026-11-03
> 上游：`005-api-contract.md`、`002-spec.md` ｜ 实现：`apps/web/`
> 设计目标：**像一套真的运营后台，而不是 AI 生成的落地页。** 数据密集、克制、可扫读、可下钻。

---

## 1. 设计方向

**关键词**：编辑部数据台 / 运营驾驶舱 / 纸质报表的温度 + 现代工具的精度。

- 暖纸底色 + 墨黑文字 + 深青主色，像一份被认真排版的周报；
- 大量表格与数字，留白服务于扫读，不做营销式大标题、渐变、插画、玻璃拟态；
- 状态用颜色 + 文字 + 形状三重编码，不依赖颜色单独传达；
- 动效只用于反馈（hover、抽屉、Toast），时长 120–240ms，不用滚动动画；
- 界面语言中文，术语与 PRD 一致（质检、复核、badcase、预警、线索）。

**明令禁止**：渐变大按钮、发光阴影、圆角 24px+ 的卡片堆叠、emoji 图标、无意义插画、居中的营销大标题、紫蓝 AI 配色、假 3D、超过 2 级的卡片嵌套。

### 2.2 字体

| 用途 | 字体栈 | 字号/行高/字重 |
|---|---|---|
| 正文 | `-apple-system, "SF Pro Text", "PingFang SC", "Noto Sans SC", "Microsoft YaHei", sans-serif` | 14/22，400 |
| 表格 | 同上，数字 `font-variant-numeric: tabular-nums` | 13/18 |
| 页面标题 | 同上 | 20/28，600 |
| 区块标题 | 同上 | 15/22，600 |
| 说明/标签 | 同上 | 12/18，400，`letter-spacing: .02em` |
| 大数字（KPI） | `"Iowan Old Style", "Songti SC", Georgia, serif` | 34/40，600，tabular |
| 代码/ID | `"SF Mono", "JetBrains Mono", Menlo, monospace` | 12/18 |

- 中文字体不引入网络字体（离线要求），走系统字体。
- 数字全部使用 `tabular-nums`，保证列对齐。
- 标题不用斜体、不用全大写英文。

### 2.3 空间与形状

- 间距基数 4px：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48`。
- 圆角：卡片 10px、输入/按钮 6px、徽标 4px、抽屉 0（贴右）、头像圆。
- 边框：统一 1px `--line`；不使用 2px 以上的装饰边框（例外：KPI 卡顶部状态条 2px）。
- 阴影：仅抽屉 `0 8px 32px rgba(20,22,26,.12)` 与 Toast；卡片无阴影。
- 布局：侧边栏 232px 固定；内容区 `padding: 24px 32px 48px`；内容最大宽度 1440px；页面最小宽度 1024px。

### 2.4 图标

- `lucide-react`，尺寸 16/18/20，`stroke-width: 1.75`，颜色继承文字。
- 状态用圆点/方块，不用 emoji；导航图标固定：总览 LayoutDashboard、质检 ClipboardCheck、badcase AlertTriangle、舆情 Radar、线索 Send、评测 FlaskConical、关于 Info。

## 3. 全局框架

```text
┌──────────────┬──────────────────────────────────────────────────────────────┐
│ QCC          │  页面标题 / 面包屑            [时间范围] [重置演示数据] 演示态 │
│ 质量工作台    ├──────────────────────────────────────────────────────────────┤
│              │                                                              │
│ ● 运营总览    │   内容区（最大 1440px，24/32 padding）                        │
│ ● 质检工作台  │   ┌ 统计条 ─────────────────────────────────────────────┐    │
│ ● badcase    │   │ 数字 · 数字 · 数字 · 数字                           │    │
│ ● 舆情预警    │   └────────────────────────────────────────────────────┘    │
│ ● 线索传递    │   ┌ 筛选栏 ────────────────────────────────────────────┐    │
│ ● 评测中心    │   └────────────────────────────────────────────────────┘    │
│              │   ┌ 主内容：表格 / 看板 / 图表 ───────────────────────┐    │
│ ───────────  │   └────────────────────────────────────────────────────┘    │
│ 数据版本      │                                                              │
│ 规则引擎      │                                                              │
└──────────────┴──────────────────────────────────────────────────────────────┘
```

- 侧边栏底部：`datasetVersion`、`modelVersion`、当前演示时刻（如「演示时刻 11-03 10:00」）。
- 顶栏右侧：时间范围切换（7d/14d/30d，仅看板/统计页）、`重置演示数据`（危险确认弹窗）、「演示态」标签（无鉴权说明 tooltip）。
- 全局 Toast：右下角，宽 360px，含图标 + 标题 + 一行详情，4s 自动消失，可手动关闭。
- 404 页：一句说明 + 返回总览按钮，不使用插画。

### 3.1 通用交互约定

- 所有列表筛选写入 URL query（`?status=open&tag=attitude`），刷新/分享保持；下钻链接直接用 query。
- 列表行 hover 底色 `--surface-alt`；可点击行 `cursor: pointer`，键盘 Enter 打开详情。
- 抽屉/弹窗支持 Esc 关闭；焦点锁定在抽屉内，关闭后回到触发元素。
- 加载态：统计条用 4 个骨架块，表格用 6 行骨架；不使用整页 spinner。
- 空态：图标 + 一句「当前筛选下没有记录」+ 清除筛选按钮。
- 错误态：红字一行 + 重试按钮；不暴露 stack。
- 所有破坏性操作（重置、驳回、关闭）需二次确认。

## 4. 组件规范

### 4.1 状态徽标 Badge
- 结构：8px 圆点 + 文字，背景为 `*-wash`，文字为对应深色，4px 圆角，padding 2px 8px，字号 12。
- 映射：
  - 判定：通过 ok、违规 danger；
  - 复核：待复核 warn、已复核 muted；
  - badcase：待处理 info、处理中 warn、待验证 info、已闭环 ok、已超期 danger（叠加）；
  - 预警：P0 danger、P1 warn、P2 info、已解决 ok；
  - 线索：草稿 muted、已分派 info、已接受 ok、已拒绝 danger、已关闭 muted。
- 级别/状态必须同时有文字，禁止只显示色块。

### 4.2 KPI 卡
- 结构：顶部 2px 状态条（ok/warn/bad）→ 标签 12px muted → 大数字 34px serif → 目标行「目标 ≥90%」→ 变化值（较上周期，▲/▼ + 数值）。
- 可点击卡右下角有 `↗` 提示；点击按 rule 下钻（见 5.1）。
- 卡高统一 132px，四列栅格（≥1280px），1024px 两列。

### 4.3 数据表格
- 表头：12px、muted、`background: --surface-alt`、下边框 1px、sticky top 0。
- 行高：44px（密集）/ 56px（含两行）；列间距 16px；首列可含标题+副标题两行。
- 对齐：文本左对齐、数字右对齐、状态居中。
- 分页：右下角「共 N 条 · 第 x/y 页」+ 上一页/下一页按钮；pageSize 固定 20。
- 排序表头：可排序列显示 `↑/↓`，当前排序列文字为主色。
- 行内操作最多 2 个文字按钮；更多操作进抽屉。

### 4.4 抽屉详情（右侧 560px）
- 顶部：类型标签 + 标题 + ID（mono）+ 关闭按钮；
- 主体：分区块（概览 / 证据 / 时间线 / 操作）；
- 底部操作条：主按钮在右，次按钮在左，固定到底部；
- 遮罩 `rgba(20,22,26,.32)`；抽屉内容滚动，头尾固定。

### 4.5 证据引用 Evidence
- 在对话转写中：命中消息左侧 2px 主色竖条 + 浅主色底；右侧悬浮 `seq 12` mono 小 chip。
- 在详情面板中：引用块 `「原文」` + 规则 ID + 置信度。
- 证据 quote 必须来自原文；前端只做高亮，不拼接句子。

### 4.6 时间线 Timeline
- 竖线 1px `--line`；节点 8px 圆点（当前节点主色，历史灰）；
- 每条：动作名（中文）、操作人、时间（MM-DD HH:mm）、备注（可选）；
- 最新事件在顶部（badcase/预警/线索统一）。

### 4.7 图表（纯 SVG，无图表库）
- 折线图：高 220px，X 轴日期 12px muted，Y 轴 4 条网格线（1px `--line`，虚线），主序列 2px `--chart-1`，参考目标线 1px 虚线 `--chart-4`，数据点 hover 显示 tooltip。
- 柱状/条形：用于分布（标签、来源、主题），条高 8px，圆角 4px，数值右对齐。
- 环形图：仅用于 P0/P1/P2 构成，中心显示总数；不超过 4 段。
- 图例在图表上方右侧，12px，圆点 + 文字。
- 无数据时显示「暂无数据」文本，不画空坐标系。

### 4.8 表单
- 输入框高 36px，1px 边框，focus 时主色边框 + 2px 浅色外环；标签在上方 12px。
- 下拉使用原生 select 样式化；多选标签用可勾选 chip。
- 校验错误显示在字段下方 12px 红字，不弹窗。
- 主按钮：主色底白字，高 36px；次按钮：白底 1px 边框；文字按钮：主色无底。

## 5. 页面规格

### 5.1 `/` 运营总览
1. 页面标题「运营总览」+ 副标题「质检、舆情、闭环与线索的一屏体检」。
2. KPI 区（7 张，4+3 两行）：质检覆盖率、质检准确率、badcase 闭环率、P0 首响、预警准确率、线索闭环率、满意度。点击下钻：
   - 质检类 → `/qc?tab=overview`；badcase → `/badcases?status=open`；P0 首响 → `/sentiment?tab=alerts&level=P0`；线索 → `/clues`；满意度/准确率 → `/eval`。
3. 异常条：横向卡片列表（最多 4 条），每条 `指标名 · 当前 vs 目标 · 责任人 · 建议`，点击按 `drillType+drillFilter` 跳转；bad 级左侧 2px 红条，warn 级琥珀条。
4. 趋势区：两栏。左「质检质量」折线（覆盖率、准确率），右「舆情与闭环」折线（P0 首响、预警准确率）；右上角 7d/14d/30d 切换。
5. 分布区：三栏。标签分布（条形）、预警级别构成（环形）、渠道/来源分布（条形）。
6. 待办区：「需要你处理」列表：待复核 N、超期 badcase N、未响应 P0/P1 N、草稿线索 N，每项右侧箭头跳转。
7. 页脚小字：数据版本、规则引擎版本、演示时刻。

### 5.2 `/qc` 质检工作台
- 统计条（4）：已检测、违规率、待复核、复核占比。
- 筛选栏：搜索（对话/坐席/ID）、判定、标签、复核状态、渠道、排序；右侧「仅看待复核」快捷开关。
- 表格列：对话（标题摘要 + ID）、渠道、坐席、开始时间、评分（数字 + 80px 进度条）、判定、标签（最多 3 个 +N）、复核、`查看` 按钮。
- 行点击打开质检详情页（不是抽屉，便于深链）。
- 底部分页。
- URL 参数：`q, verdict, tag, review, channel, sort, page`。

### 5.3 `/qc/:id` 质检详情
- 顶部：返回链接 + 对话 ID（mono）+ 渠道/坐席/时间 + 判定徽标 + 「创建 badcase」主按钮（已有则显示 badcase 状态并链接）。
- 左栏（约 58%）：对话转写，气泡区分客户/坐席，时间戳与间隔；证据消息高亮；超时消息显示「间隔 203s」红色 chip。
- 右栏（约 42%，sticky）：
  1. 评分卡：分数大字 + 进度环/条 + 判定；
  2. AI 摘要 + 情绪 + 置信度（带「低置信度」提示）；
  3. 标签列表（折叠项）：标签名、扣分、置信度、证据引用、规则 ID；
     - `wrong_knowledge` 额外显示知识依据卡：KB 编号 + 标题、标准口径、坐席陈述（标准值 vs 实际值），点击跳知识条目；
     - 未关联知识条目时显示「知识库未覆盖」提示与「生成知识完善草稿」按钮；
  4. 复核区：若待复核，三个按钮「确认判定 / 推翻判定 / 修正标签」+ 备注；修正时勾选标签；提交后展示复核结论；
  5. 已复核：显示复核人、结论、备注、时间；
  6. badcase 区：无则引导创建（类别、负责人自动带出、SLA、标题/根因预填）；有则显示状态、责任人、SLA、链接。
- 创建 badcase 用模态：类别（4 选 1 卡片）、责任人（按类别自动）、SLA（24/48/72）、标题、根因描述；提交后 Toast + 右侧状态刷新。

### 5.4 `/badcases` badcase 闭环
- 统计条（5）：总数、待处理、处理中、待验证、已闭环；右侧显示闭环率与超期数（红色）。
- 视图切换：`列表 / 看板`。列表为表格；看板为 4 列（open/in_progress/pending_verify/closed），卡片显示标题、类别、责任人、SLA 倒计时、复发标记；列头计数。
- 筛选：状态、类别、负责人、搜索。
- 详情抽屉（560px）：标题 + 编号 + 状态徽标；元信息（类别、责任人、严重度、SLA 截止、创建人）；根因；证据引用（跳质检详情）；复发提示条；时间线；操作区按状态显示：分派/开始处理/提交验证/验证通过(关闭，需证明)/驳回重开/评论。
- 关闭操作必须填写「闭环证明」（如：知识库条目已更新 KX-1024 / 话术已培训 11-02 场次），否则前端提示且后端 422。
- 看板卡片点击同样打开抽屉；拖动不做（MVP 用按钮推进状态，避免误操作）。

### 5.5 `/sentiment` 舆情预警
- 顶部两个 Tab：`预警`（默认）/ `评论`；URL `?tab=alerts|comments`。
- 统计条（5）：评论数、负面占比、预警总数、未关闭、待复核。
- 预警 Tab：筛选（级别、状态、搜索）；表格列：级别（P0/P1/P2 徽标）、主题、标题、状态、责任人、SLA 截止（含倒计时/超期）、评论数、首响、`处理`。P0 行左侧 2px 红条。
- 评论 Tab：筛选（来源、情感、主题、级别、搜索）；表格列：评论摘要、来源、品牌、发布时间、情感（分数）、主题、单条级别、置信度、`关联预警`。
- URL 参数同步。

### 5.6 `/sentiment/alerts/:id` 预警处置
- 顶部：返回 + 级别徽标 + 标题 + 状态 + SLA 倒计时（超期红）。
- 三栏布局（左 62% / 右 38%）：
  - 左：事件概述、触发规则列表（ruleId + 描述）、评论证据列表（原帖 + 来源 + 时间 + 情感 + 级别，可折叠）、关联线索。
  - 右：SOP 行动区（确认收到 / 响应中（填写对外口径）/ 升级 / 标记解决（填写结论）/ 评论）、责任人、首次响应时间、时间线。
- 底部：「生成线索」按钮 → 模态选择目标（品牌/市场/产研）与优先级、标题/描述预填；成功 Toast 并显示关联线索。
- 对外口径输入框有免责提示「仅内部记录，不自动对外发布」。

### 5.7 `/clues` 线索传递
- 统计条（4）：总数、待分派、已接受、已关闭；右侧闭环率。
- 视图：`表格 / 看板`（5 列：draft/routed/accepted/rejected/closed），默认表格。
- 表格列：标题、来源（类型 + 来源对象链接）、目标、优先级、责任人、状态、更新时间、`查看`。
- 「新建线索」按钮 → 模态：标题、描述、来源类型（qc/sentiment/dashboard/agent）、关联对象（可选下拉）、目标、优先级、证据（多行）。
- 详情抽屉：标题 + 来源链接 + 目标 + 优先级 + 状态 + 时间线 + 操作（分派/接受/拒绝（需理由）/关闭（需结论）/评论）。
- 卡片/行显示来源跳转：qc → 质检详情；sentiment → 预警详情；dashboard → 看板。

### 5.8 `/eval` 评测中心
- 顶部说明：规则引擎版本、数据集版本、评测口径链接（`docs/metric-dictionary.md` 不可点则文本展示）。
- 数据集卡（2）：质检评测集、舆情评测集；显示条目数、版本、最近运行时间、门禁状态（达标数/总数）、「运行评测」按钮（运行中禁用 + 文案「运行中…」）。
- 指标区：按数据集分组的指标表，列：指标、值、目标、门禁（通过/未通过徽标）；未通过行浅红底。
- 混淆矩阵：质检 2×2 / 舆情 3×3 小表，数字 tabular。
- 错例列表：最多 20 条，显示 itemId、期望、预测、原因；可展开原文（若数据集包含）。
- 历史：最近 10 次运行，时间、数据集、关键指标、门禁结果。
- 文案必须写明「指标基于合成评测集，规则引擎基线，不代表线上泛化能力」。

### 5.9 `/about` 关于与边界
- 产品一句话定位与三模块说明；
- 「不做什么」列表（完整客服系统/模型训练/全渠道爬虫/自动处罚/自动对外发布）；
- 指标口径摘要表 + 链接到 docs；
- 技术栈与运行方式、端口；
- 数据声明：合成数据、无外部调用、无鉴权仅本机演示；
- 版本信息：产品版本、数据集版本、引擎版本、演示时刻；
- 快捷键：`g d` 总览、`g q` 质检、`g s` 舆情、`g b` badcase、`g c` 线索、`g e` 评测（可选实现）。

### 5.10 `/knowledge` 知识库
- 页面标题「知识库」+ 副标题「质检口径、知识缺口与完善闭环」；右侧「新建条目」主按钮。
- 统计条（4）：已发布、草稿、知识错误关联率、待完善缺口（缺口 > 0 时用警示色）；数字旁注明「/ 条目总数」「条」。
- 知识缺口面板（无缺口时隐藏）：
  - 每条：规则/案例标题、出现次数、样例会话与原文引用、责任人；
  - 操作：「查看会话」跳 `/qc/{id}`，「生成草稿」调用 suggestions 后跳 `/knowledge/{id}`。
- 筛选：搜索（编号/标题/关键词）、状态、分类、来源；URL 同步 `q,status,category,source,page`。
- 表格列：编号（mono）、标题 + 关键词、分类、版本、状态徽标、知识错误命中（linked/total）、关联 badcase 数、更新时间、`查看`。
- 行点击进入详情；底部分页。

### 5.11 `/knowledge/:id` 知识条目详情
- 顶部：返回 + 编号（mono）+ 状态徽标 + 版本 + 分类 + 来源；右侧操作按状态：
  - draft：「编辑修订」「发布」（无有效事实时禁用并提示）；
  - published：「编辑修订」「下线」「复测」；
  - offline：「编辑修订」「发布」。
- 左栏（约 62%）：
  1. 标准口径卡片：正文、关键词、责任人、生效/更新时间、来源（可跳会话/badcase）；
  2. 事实表：事实名、标准值、比对方式、识别规则（折叠展示正则）、说明；无事实时提示「发布前请补齐至少 1 条可校验事实」；
  3. 知识错误证据：关联会话列表（会话 ID、坐席、命中原文、标准值 vs 实际值），点击跳质检详情；
  4. 关联 badcase：编号、标题、状态、责任人，点击跳详情。
- 右栏（约 38%）：
  1. 复测卡：最近一次复测时间、复测会话数、变化会话数、关联率前后；
  2. 版本历史：版本号、状态、修订人、时间、修订原因；可展开查看该版本的事实快照。
- 修订模态：标题/分类/正文/关键词/事实列表（可增删；事实字段：名称、标准值、比对方式、期望数值/时效/日期、识别正则每行一条、直接违规正则每行一条、说明）；提交后回到 draft。
- 发布/下线需二次确认；成功后 Toast 显示复测摘要（如「复测 57 通，1 通标签变化，知识缺口 1 → 0」）。

## 6. 响应式与可访问性

- ≥1280px：完整布局（侧边栏 + 多栏）。
- 1024–1279px：侧边栏收窄至 64px（仅图标，hover 显示名称）；KPI 两列；看板横向滚动。
- <1024px：不承诺；页面显示「建议 1280px 以上使用」提示条，内容仍可滚动。
- 对比度：正文 ≥ 4.5:1，大数字 ≥ 3:1；状态色不单独作为唯一信息。
- 键盘：Tab 顺序自然；表格行 `tabIndex=0` 可 Enter 打开；抽屉 Esc 关闭；焦点样式 `outline: 2px solid --primary; outline-offset: 2px`。
- 语义：表格用 `<table>`，按钮用 `<button>`，标题层级 h1/h2/h3 不跳级；图表加 `role="img"` + `aria-label` 摘要。
- 动效尊重 `prefers-reduced-motion`。

## 7. 文案规范

- 动词开头、短句、不用感叹号；状态用「待处理 / 处理中 / 待验证 / 已闭环」。
- AI 结果必须带「AI 初判」字样与置信度，避免被当成最终结论。
- 风险提示用中性陈述，不制造恐慌（如「该预警为 P1，需 2 小时内首次响应」）。
- 空数据写「暂无数据」；失败写「加载失败，请重试」；不用「Oops」「哎呀」。
- 数字格式：百分比 1 位小数（92.3%），时长用「32 分钟」「1 小时 12 分」，金额 `¥1,200`。
- 日期展示 `MM-DD HH:mm`，跨年显示 `YYYY-MM-DD`；时区 Asia/Shanghai。
